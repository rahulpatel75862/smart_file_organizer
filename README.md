# smart_file_organizer

A simple Python automation project that automatically organizes files into folders based on their file extensions.

🚀 Features
  Automatically sorts files into folders
  
  Supports images, PDFs, videos, and ZIP files
  
  Creates folders automatically if they do not exist
  
  Beginner-friendly Python project
  
  Uses built-in Python modules only

📂 Supported File Types

  | File Extension          | Folder   |
| ----------------------- | -------- |
| `.jpg`, `.jpeg`, `.png` | Images   |
| `.pdf`                  | PDFs     |
| `.mp4`, `.mkv`          | Videos   |
| `.zip`                  | Archives |


🛠 Technologies Used
Python

os module

shutil module
